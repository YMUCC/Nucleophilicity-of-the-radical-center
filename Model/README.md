## Model Description
This folder contains all the models required for training.

#`DecisionTree.py`:Decision Tree Model

#`GaussianProcess.py`:Gaussian Process Model

#`KNN.py`:K-Nearest Neighbors Model

#`KRR.py`:Kernel Ridge Regression Model

#`Lasso.py`:Light Gradient Boosting Machine Model

#`LGBM.py`:Least Absolute Shrinkage and Selection Operator Model

#`NN.py`:Neural Network Model

#`RF.py`:Random Forest Model

#`SVR.py`:Support Vector Regression Model

#`XGB.py`:eXtreme Gradient Boosting Model

#`External validation.py`:External validation script that performs external validation by loading the corresponding model.

#`Algorithm11Predictions-RP.py Algorithm11Results-RP.py`:These two scripts read the model training results and the specific results for each data item.
